# New World — asset provenance and licences

## Runtime atlas

The production builder uses only the `_16bit.png` source sheets in these five source categories: `houses`, `restaurants`, `stores`, `village` and `watertower`. It extracts frames 0, 8, 16 and 24 from each 8 × 4 sheet.

Current build: **147 source sheets → 588 directional sprites → 1 atlas page**.

Each of the 147 selected source sheets was matched to the corresponding local downloaded asset by SHA-256. The source names, sheet layout and pack contents align with the official pack pages below.

| Runtime categories | Source pack | Local source copy | Licence |
|---|---|---|---|
| `houses` — 49 sheets | [City Builder: Residential Houses 50 Pack](https://polyyai.itch.io/city-builder-residential-houses-50-pack) by Polyy.AI | `Downloads/house_part_1` and `Downloads/house_part_2` | CC0 1.0 Universal |
| `restaurants` + `stores` — 73 sheets | [City Builder: Commercial Buildings 73 Pack](https://polyyai.itch.io/city-builder-commercial-buildings-73-pack) by Polyy.AI | `Downloads/assets/restaurants` and `Downloads/assets/stores` | CC0 1.0 Universal |
| `village` — 12 sheets | [City Builder: Village Buildings](https://polyyai.itch.io/city-builder-village-buildings) by Polyy.AI | `Downloads/City_Builder_Village_Buildings_part_2` | CC0 1.0 Universal |
| `watertower` — 13 sheets | [City Builder: Water Towers](https://polyyai.itch.io/city-builder-water-towers) by Polyy.AI | `Downloads/City_Builder_Water_Towers_part_1` | CC0 1.0 Universal |

The local Village Buildings and Water Towers `LICENSE.txt` files also identify CC0 1.0 Universal and permit commercial use, modification, remixing and redistribution. The official Residential Houses and Commercial Buildings pages state the same CC0 terms.

## Conditions and credits

The pack pages describe CC0 1.0: commercial and non-commercial use, modification and remixing are allowed, and attribution is not required. They also ask users not to resell the original, unmodified packs as their own asset packs.

The runtime atlas is a modified selection: four individual orientations are cut from each source sheet and repacked into a game atlas. It is not a copy of the original packs distributed unchanged.

Suggested optional credit:

> Selected isometric building sprites by Polyy.AI (CC0 1.0).

## Assets deliberately excluded

- `terrain` in the private asset repository is not read by the current atlas builder. Its local Antahonist licence permits use inside released games but prohibits redistributing the tiles on their own or inside another asset pack. Keep this category out of standalone public asset downloads and out of the runtime atlas unless its use is reviewed separately.
- The separate Mythryl Studio “2D Pixel Modern City” pack found in Downloads did not produce any SHA-256 matches for the current runtime atlas source files. It is not used by this atlas and must not be mixed into it without a separate licence review.

## Verification notes

- Source verification was performed against the files present on the development PC using SHA-256 hashes.
- The atlas is generated by `Apps/NewWorld/build-spritesheet.py`; it contains only the four source categories listed in the runtime table.
- Re-run the builder and review this document whenever source categories or downloaded packs change.
