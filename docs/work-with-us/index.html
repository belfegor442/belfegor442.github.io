NORTH ASSEMBLY.

North Assembly is built around independent software, experimental systems and small projects that are meant to be useful, interesting and technically honest. Contributions can happen around a project, not only through a conventional job title.

Contact the teamExplore projects
01 · Roles

Where you can contribute.

Openings change with project needs. The roles below describe the contribution areas we use rather than promising a permanent vacancy.

Development

Software Development

Build features, fix bugs, improve architecture and turn project ideas into working software.

Engineering

Systems & Engineering

Work close to operating systems, networking, performance, tooling and lower-level technical problems.

Design

UI / UX & Graphics

Design interfaces, visual systems, assets and interaction patterns that fit the identity of each project.

Quality

Testing & QA

Break things deliberately, document reproducible problems and help projects become more reliable.

Documentation

Technical Writing

Turn implementation details into documentation, guides, changelogs and usable project references.

Management

Project Management

Coordinate work, priorities, releases and communication across independent project teams.

02 · How we work

Small teams. Real projects.

Choose a project

Start from a project whose goals and technical direction make sense to you.

Show what you can build

Portfolio work, GitHub activity, prototypes or previous contributions are more useful than a formal title.

Work directly

Contributions are organized around concrete tasks, reviews and project milestones.

Ship and document

Finished work should be understandable, testable and traceable through the project's documentation and history.

03 · Join

Want to work on something weird?

Send the team a short introduction, the area you want to contribute to and a link to relevant work. There is no need to manufacture a formal application if the useful information is already in your portfolio or repository.
