QUICK START / HOW TO PLAY

  1. Create or join a worldOpen MULTIPLAYER. The host creates a private room and shares its code.
  2. Start the frontierOnce everyone is in the founding party, the host presses START WORLD.
  3. Claim a regionSelect an UNCLAIMED State on the map, then claim it for ¤450. Your new settlement receives a development reserve.
  4. Build your settlementDouble-click your region, choose an object, press BUILD, then click an empty dry plot.
  5. Expand and manageUse ECONOMY, GOVERNMENT, MILITARY and RESEARCH to grow, negotiate and compete.

ADVANCED · HOST SCENARIO SETTINGS

Optional technical configuration for the host before the world starts. Normal play does not require editing JSON.

PUBLIC SERVICES / PROVIDERS / COVERAGE CONFIGURATION

Host-only setup before the world starts. Define service demand units, health or education outcomes, local facilities, population groups served, staffing, capacity, quality and operating costs. Public costs use the State treasury. Private, religious, community and mixed providers must reference a registered local NPC operator. No coverage is inferred from the State population.

INDUSTRY / LABOUR / WORKPLACE CONFIGURATION

Host-only setup before the world starts. Register occupations, local labour pools, existing NPC company facilities, workplace positions, daily wages, qualification requirements, shift hours, safety and recognized unions. Labour supply cannot exceed the referenced population group. Companies pay their own payroll in the State currency.

DEMOGRAPHY / POPULATION COHORT CONFIGURATION

Host-only technical setup before starting the world. Configure every represented age from 0 to 120, annual births per thousand, mortality by age band, group locations and migration permissions. Epidemic definitions require explicit incubation, infectious duration, transmission, mortality and group-to-group contact parameters plus dated outbreak seeds. No historical or disease rate is supplied by default.

JUSTICE / LEGAL SCENARIO CONFIGURATION

Technical scenario data only. Configuration is locked after the world starts. Each State must include crimeTypes, courts, policeAgencies and prisons arrays. Crime categories must reference an enacted law in force. Courts and police agencies need explicit provincial jurisdiction; police actions also require an office holder authorized by the State.

RESOURCES / CLIMATE / ENVIRONMENT CONFIGURATION

Host-only technical setup before the world starts. Configure resource definitions, finite deposits, agricultural land, crops, farms, pasture and livestock sites, fisheries, managed forest areas, water, climate seasons, environmental measurements, disasters, energy and strategic reserves. Livestock, fisheries and forestry each need their own stocks, regeneration/harvest limits and a linked NPC company installation. Every reference must point to an existing State, province, land parcel, market good or company installation. No climate, deposit, herd, catch, timber or yield defaults are assumed.

ADMINISTRATION / AGENCIES / CIVIL SERVICE CONFIGURATION

Host-only setup before starting the world. Configure agencies, competence and provincial jurisdiction, departments, permanent civil-service posts, legal procedures triggered by policy or law, budget accounts, public projects, milestones and suppliers. Political supervisory offices must already exist. Employees are not deleted when political office holders change.

MEDIA / PUBLIC OPINION / PRESS RULES CONFIGURATION

Host-only setup before the world starts. Configure every State's press-freedom rules, legal restriction powers, registered outlets, editorial profiles, reach, credibility, independence, licensed editors, topic coverage and public-opinion baselines. News reports later cite real world events. A censorship law must explicitly authorize media restrictions and an existing office must be assigned.

SECURITY / INTELLIGENCE / OVERSIGHT CONFIGURATION

Host-only setup before the world starts. Define each security agency's scope, competence, province, investigation offices and separate oversight offices. Every authorization must reference a law currently in force, a competence, a territory, a warrant requirement and a review interval. Do not configure powers that are not explicitly supported by the scenario's laws.

WORLD EVENTS / TRIGGERS / OUTCOMES CONFIGURATION

Host-only setup before the world starts. Define events by State, date window, deterministic daily probability (0–1,000 per thousand), occurrence limit, cooldown, expiry, required decision offices and explicit options. Supported effects are limited to State treasury, configured opinion topics, configured press-freedom rules and existing resource stock. Every effect is prevalidated before any part is applied.

IDENTITY / RELIGION / IDEOLOGY / COMMUNITY CONFIGURATION

Host-only setup before the world starts. Configure aggregated groups and provincial profiles, rights, recognition, language/service access, grievance and trust. Communities may overlap; mark those groups non-exclusive. Organizations require an active law, valid province, registered office, bounded programme costs and capacities. Never enter names or private beliefs of individual residents.
