# NewWorld interface icon sources

## Existing building artwork

The navigation, section headings and construction-category icons use the colored building sprites already present in sprite-manifest.json and spritesheet-01.png. The UI draws individual sprite regions from the existing atlas at runtime; it does not use emoji characters or externally hosted images.

## Kenney Medieval RTS

- Source: https://kenney.nl/assets/medieval-rts
- Original creator: Kenney Vleugels (Kenney.nl)
- Included asset: kenney-medieval-rts/military-unit.png (a cropped 16 px unit sprite from medievalUnit_01.png)
- License: CC0 1.0. The original License.txt is kept beside the asset.
- Use: MILITARY navigation tab.

## SpritePilot UI & Feedback Pack

- Source: https://spritepilot.com/free-game-assets/ui
- Included assets: static preview PNGs for check, warning, failure, health, research, objective and information states.
- License: CC0 1.0. The original LICENSE.txt and README.txt are kept in the downloaded pack.
- Use: semantic status marks in political, economic, civic and event rows.
- The source author states these assets were drawn by code and are not AI-generated.

All referenced image files are stored locally in assets/; the interface makes no runtime requests to these asset websites.
