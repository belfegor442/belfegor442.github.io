Security built in,
not bolted on

  • 01

    AES-256-GCM Encryption

    Military-grade encryption for all your data. Each file encrypted with a unique key derived from your master password.

  • 02

    PBKDF2 Key Derivation

    100,000 iterations of PBKDF2-SHA256. Brute-force resistant even with powerful hardware.

  • 03

    HMAC Integrity Verification

    Every file verified on load. Tampered data is detected and rejected immediately.

  • 04

    Local-First Architecture

    No cloud sync, no telemetry, no tracking. Your data never leaves your machine. Period.

  • 05

    Auto-Lock & Timeout

    Vault locks automatically when idle. Configurable timeout from 1 to 60 minutes.
