Meat.

An experimental software project exploring interaction, unusual mechanics and software behavior.

Development / experimental
01 / CONCEPT

Built to explore.

Meat is deliberately positioned as an experimental project. Its focus is interaction, unusual mechanics and the ways software can behave when the normal assumptions are changed.

The project is still developing, so its public scope is expected to change as its systems and mechanics become more stable.
