Visual identity

The visual language for North Assembly: dark technical surfaces, restrained typography, purple/pink accents, clear hierarchy and consistent project navigation.

02 · Typography

Technical voice

Headings use large, tight system sans-serif typography. Metadata, labels, navigation and technical information use a monospace face with uppercase tracking.

INTER / SYSTEM + MONOSPACE
03 · Surfaces

Interface language

Use dark panels, thin borders, subtle gradients and restrained glow. Cards should feel like instruments rather than decorative marketing blocks.

04 · Motion

Controlled movement

Hover elevation and border transitions are short and functional. Reduced-motion preferences are respected throughout the interface.

05 · Rules

Consistency over decoration

  • Keep navigation predictable across portal pages.
  • Use status labels as factual state indicators, not marketing claims.
  • Do not invent product capabilities, releases or download artifacts.
  • Keep accessibility, responsive layouts and reduced motion as baseline requirements.
  • Project-specific visual differences may exist, but should remain compatible with the core system.
