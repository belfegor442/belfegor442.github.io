About.

Weird Stuff is an independent software studio building complete software, tools and experimental systems from the ground up.

What we do

We work across system tooling, data platforms, editors, network experiments and other software projects. The common approach is practical: build, test, break, improve.

Projects can be active, experimental or archived. Status is published openly so the state of each project is clear.
